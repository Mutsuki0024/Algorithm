# 动态规划（DP）复习项目计划

> 目标：系统复习常见动态规划模型。重点不是背模板，而是恢复 **状态设计 →
> 状态转移 → 初始化 → 计算顺序 → 复杂度/空间优化** 的完整分析能力。

## 总体路线

``` text
线性 DP
  ↓
背包 DP
  ↓
序列 DP
  ↓
区间 DP
  ↓
树形 DP
  ↓
状态压缩 DP
  ↓
数位 DP
  ↓
陌生题状态设计
  ↓
DP 优化
```

------------------------------------------------------------------------

## 1. 线性 DP

**状态：已复习**

### 核心内容

-   一维状态 `dp[i]`
-   从"最后一步/最后一个决策"推导状态转移
-   方案数、最大值、最小值三类转移
-   "前 i 个元素"与"以 i 结尾"的状态含义
-   空间优化

### 典型问题

-   Fibonacci / 爬楼梯
-   打家劫舍
-   最大子数组和

### 核心能力

``` text
状态定义
→ 最后一个决策
→ 找到子问题
→ 写出状态转移
```

------------------------------------------------------------------------

## 2. 背包 DP

**状态：已复习主体**

### 2.1 0/1 背包

每件物品最多选择一次。

核心转移：

``` python
for w, v in items:
    for j in range(W, w - 1, -1):
        dp[j] = max(dp[j], dp[j - w] + v)
```

关键：

-   容量倒序
-   防止当前物品重复使用

### 2.2 完全背包

每种物品可以无限使用。

``` python
for w, v in items:
    for j in range(w, W + 1):
        dp[j] = max(dp[j], dp[j - w] + v)
```

关键：

-   容量正序
-   允许读取本轮已经更新的状态

### 2.3 多重背包

每种物品最多使用 `c[i]` 次。

需要掌握：

-   朴素枚举数量
-   二进制拆分
-   转换为若干个 0/1 物品
-   后续 DP 优化阶段再学习单调队列优化

二进制拆分思想：

``` text
13 → 1 + 2 + 4 + 6
```

把"选择 0～13 个"转换为若干个"选/不选"的 0/1 决策。

### 2.4 背包的不同目标

背包不只是最大价值：

  问题           DP 存储内容
  -------------- -------------
  最大收益       `max`
  最小代价       `min`
  是否能够达到   `bool`
  方案数量       `count`

### 2.5 恰好装满与不超过容量

容量不超过 `W` 求最大值：

``` python
dp = [0] * (W + 1)
```

必须恰好达到容量 `W`：

``` python
dp[0] = 0
dp[1:] = [-inf] * W
```

不可达状态：

-   求最大值：`-inf`
-   求最小值：`+inf`

### 2.6 循环顺序

两个问题必须分开理解：

**容量正序/倒序：控制一个物品能使用几次**

``` text
0/1 背包：倒序
完全背包：正序
```

**物品/容量谁在外层：计数型完全背包中控制组合与排列**

``` text
物品在外 → 组合数
容量在外 → 排列数
```

### 2.7 "凑出 target"为什么是背包

建立映射：

``` text
数字          → 物品重量
target        → 背包容量
每个数一次    → 0/1 背包
每个数无限次  → 完全背包
每个数最多 k 次 → 多重背包
能否凑出      → bool 型背包
多少种凑法    → 计数型背包
```

## 3. 序列 DP

**状态：正在复习**

计划顺序：

``` text
LIS
 ↓
LCS
 ↓
编辑距离
```

### 3.1 LIS：最长递增子序列

基础状态：

``` text
dp[i] = 以 nums[i] 结尾的 LIS 长度
```

转移：

``` text
dp[i] = max(dp[i], dp[j] + 1)
条件：j < i 且 nums[j] < nums[i]
```

Python：

``` python
dp = [1] * n

for i in range(n):
    for j in range(i):
        if nums[j] < nums[i]:
            dp[i] = max(dp[i], dp[j] + 1)

answer = max(dp)
```

复杂度：

``` text
时间 O(n²)
空间 O(n)
```

后续：

-   LIS 的 `O(n log n)` 二分优化
-   `tails` 数组的真正含义

### 3.2 LCS：最长公共子序列

待复习：

-   `dp[i][j]` 状态设计
-   两个序列的前缀
-   相等/不相等时的状态转移
-   二维 DP
-   空间压缩

### 3.3 编辑距离

待复习：

-   插入
-   删除
-   替换
-   `dp[i][j]` 的语义
-   从"最后一次操作"推导转移

## 4. 区间 DP

待复习。

核心状态：

``` text
dp[l][r] = 区间 [l, r] 上的最优答案
```

重点：

-   为什么按区间长度递增计算
-   枚举分割点 `k`
-   大区间如何由小区间构成

典型问题：

-   矩阵链乘法
-   石子合并
-   回文相关问题

典型结构：

``` python
for length in range(2, n + 1):
    for l in range(...):
        r = l + length - 1
        for k in range(l, r):
            # transition
            pass
```

## 6. 状态压缩 DP

待复习。

重点：

-   bitmask 表示集合
-   `dp[mask]`
-   `dp[mask][i]`
-   位运算
-   枚举子集
-   集合状态之间的转移

典型问题：

-   TSP（旅行商问题）
-   小规模集合选择/匹配问题

典型复杂度：

``` text
O(2^n · n)
O(2^n · n²)
```

适合 `n` 较小但普通排列搜索过大的问题。

# 8. 陌生题的 DP 状态设计

经典模型复习结束后，重点训练这一部分。

不以"这是什么类型的 DP"为第一问题，而是按以下流程：

``` text
1. 原问题要求什么？
2. 最后一个决策是什么？
3. 做完这个决策后，剩下什么子问题？
4. 为了描述这个子问题，必须保留哪些信息？
5. 这些信息能否构成状态？
6. 状态之间如何转移？
7. 是否存在重复计算？
8. 最终答案对应哪个状态？
```

重点训练：

-   如何发现重叠子问题
-   如何判断状态信息是否充分
-   "前 i 个"与"以 i 结尾"
-   从暴力 DFS 推导记忆化搜索
-   从记忆化搜索推导递推 DP
-   如何证明转移不漏解、不重复
-   如何识别复合 DP（如网格 + 背包状态）

# 学习原则

整个项目不以背模板为目标。

每种 DP 都优先回答：

``` text
dp 状态到底表示什么？
↓
为什么需要保存这些信息？
↓
最后一步有哪些可能？
↓
它依赖哪些已经解决的子问题？
↓
为什么这个转移覆盖全部情况？
↓
初始化为什么这样设置？
↓
计算顺序为什么正确？
↓
时间/空间复杂度是多少？
↓
能否进一步优化？
```

最终目标是：

> 看到陌生问题时，能够从问题结构自行构造状态和转移，而不是依赖识别某个固定模板。
