# 1. 图的表示与基本概念

需要掌握：

-   有向图 / 无向图
-   加权图 / 无权图
-   入度 / 出度
-   路径、环、连通分量
-   树与森林
-   稀疏图 / 稠密图
-   邻接表与邻接矩阵

Python 邻接表：

``` python
graph = [[] for _ in range(n)]

for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)
```

带权边：

``` python
graph[u].append((v, w))
```

邻接表空间复杂度：

``` text
O(V + E)
```

邻接矩阵空间复杂度：

``` text
O(V²)
```

# 2. DFS 与 BFS

## DFS

``` python
def dfs(u):
    visited[u] = True

    for v in graph[u]:
        if not visited[v]:
            dfs(v)
```

重点：

-   连通分量
-   环检测
-   路径搜索
-   DFS 树
-   回溯
-   图上的状态搜索

## BFS

``` python
from collections import deque

q = deque([start])
dist = [-1] * n
dist[start] = 0

while q:
    u = q.popleft()

    for v in graph[u]:
        if dist[v] == -1:
            dist[v] = dist[u] + 1
            q.append(v)
```

关键：

> BFS 可以求无权图 / 单位权图最短路。

复杂度：

``` text
O(V + E)
```

## 多源 BFS

多个起点同时入队。

典型：

-   最近距离
-   多个源点扩散
-   网格距离问题

# 3. 拓扑排序与 DAG

适用于有向无环图。

典型：

-   课程依赖
-   任务依赖
-   先后关系

## Kahn 算法

``` python
from collections import deque

indegree = [0] * n

for u in range(n):
    for v in graph[u]:
        indegree[v] += 1

q = deque(i for i in range(n) if indegree[i] == 0)
order = []

while q:
    u = q.popleft()
    order.append(u)

    for v in graph[u]:
        indegree[v] -= 1
        if indegree[v] == 0:
            q.append(v)
```

若：

``` python
len(order) < n
```

说明存在有向环。

复杂度：

``` text
O(V + E)
```

还需要掌握：

-   DFS 拓扑排序
-   三色标记检测有向环
-   DAG DP
-   DAG 最长路 / 最短路 / 方案计数

# 4. 最短路径

学习顺序：

``` text
BFS
→ Dijkstra
→ Bellman-Ford
→ Floyd-Warshall
→ 0-1 BFS
```

## Dijkstra

适用：

``` text
单源最短路 + 非负边权
```

``` python
import heapq

INF = float("inf")
dist = [INF] * n
dist[start] = 0

pq = [(0, start)]

while pq:
    d, u = heapq.heappop(pq)

    if d != dist[u]:
        continue

    for v, w in graph[u]:
        nd = d + w

        if nd < dist[v]:
            dist[v] = nd
            heapq.heappush(pq, (nd, v))
```

复杂度：

``` text
O((V + E) log V)
```

重点：

-   松弛
-   为什么不能直接处理负边
-   堆中旧状态为什么可以跳过

## Bellman-Ford

适合存在负权边的单源最短路。

重点：

-   对所有边重复松弛
-   为什么最多 `V - 1` 轮
-   负环检测

复杂度：

``` text
O(VE)
```

SPFA 作为 Bellman-Ford 的队列优化理解即可，注意最坏复杂度较差。

## Floyd-Warshall

所有点对最短路：

``` python
for k in range(n):
    for i in range(n):
        for j in range(n):
            dist[i][j] = min(
                dist[i][j],
                dist[i][k] + dist[k][j]
            )
```

复杂度：

``` text
O(V³)
```

重点理解其 DP 含义：

> 允许使用前 k 个节点作为中间节点。

## 0-1 BFS

适用：

``` text
边权只有 0 和 1
```

使用双端队列：

``` text
权重 0 → 队首
权重 1 → 队尾
```

复杂度：

``` text
O(V + E)
```

## 算法选择

  图的条件        算法
  --------------- --------------
  无权 / 单位权   BFS
  0/1 权值        0-1 BFS
  非负权单源      Dijkstra
  存在负权        Bellman-Ford
  负环检测        Bellman-Ford
  全源且 V 较小   Floyd
  DAG             拓扑序 + DP

# 5. 并查集 DSU

支持：

``` text
find(x)
union(x, y)
```

重点：

-   路径压缩
-   按大小 / 按秩合并

``` python
parent = list(range(n))
size = [1] * n

def find(x):
    if parent[x] != x:
        parent[x] = find(parent[x])
    return parent[x]

def union(a, b):
    a = find(a)
    b = find(b)

    if a == b:
        return False

    if size[a] < size[b]:
        a, b = b, a

    parent[b] = a
    size[a] += size[b]
    return True
```

均摊复杂度：

``` text
O(α(n))
```

典型：

-   动态连通
-   判断成环
-   连通分量
-   Kruskal

# 6. 最小生成树 MST

问题：

> 用最小总代价连接所有节点。

## Kruskal

``` text
边按权值排序
→ 从小到大尝试
→ DSU 判断是否形成环
```

复杂度：

``` text
O(E log E)
```

重点：

-   DSU
-   Cut Property
-   为什么贪心成立

## Prim

``` text
从一个节点集合开始
→ 每次加入连接集合内外的最小边
```

堆优化：

``` text
O(E log V)
```

需要区分 Prim 与 Dijkstra：

-   Dijkstra：维护源点到节点的最短距离
-   Prim：维护节点接入当前生成树的最小边权

# 8. 强连通分量 SCC

针对有向图。

强连通：

``` text
u → v 可达
且
v → u 可达
```

学习：

-   Tarjan
-   Kosaraju
-   `dfn`
-   `low`
-   栈
-   SCC 缩点

核心结论：

``` text
任意有向图
→ SCC 缩点
→ DAG
```

# 9. 割点、桥与双连通

针对无向图。

桥：

> 删除该边后连通分量数量增加。

割点：

> 删除该节点后连通分量数量增加。

重点：

-   DFS 树
-   `dfn`
-   `low`
-   Tarjan low-link

桥的重要判定：

``` text
low[v] > dfn[u]
```

后续扩展：

-   点双连通分量
-   边双连通分量
-   缩点

# 10. 树上图论

树：

``` text
连通 + 无环
```

复习：

-   DFS / BFS
-   深度
-   父节点
-   子树大小
-   树的直径
-   LCA
-   倍增
-   欧拉序

## 树的直径

常见：

``` text
两次 DFS / BFS
```

以及树形 DP 解法。

## LCA

Binary Lifting：

``` text
up[u][k] = u 的 2^k 级祖先
```

复杂度：

``` text
预处理 O(N log N)
单次查询 O(log N)
```

# 11. 欧拉路径与欧拉回路

需要区分：

``` text
Euler Path / Circuit

```

# 13. 图论综合建模

经典算法复习完后重点训练。

看到题目先问：

``` text
1. 什么是节点？
2. 什么关系是边？
3. 边有没有方向？
4. 边权表示什么？
5. 求的是可达性、距离、连通性、依赖还是匹配？
6. 图有没有特殊结构？
7. 数据范围允许什么复杂度？
```

典型识别：

``` text
最少步数
→ BFS

非负代价最短路
→ Dijkstra

依赖关系
→ 拓扑排序

连接所有节点的最小总代价
→ MST

动态连通
→ DSU

两组对象匹配
→ 二分图 / 网络流

互相可达
→ SCC

关键连接
→ 桥 / 割点
```

# 复杂度速查

  算法              典型复杂度
  ----------------- --------------------
  DFS / BFS         `O(V + E)`
  拓扑排序          `O(V + E)`
  Dijkstra + Heap   `O((V + E) log V)`
  Bellman-Ford      `O(VE)`
  Floyd-Warshall    `O(V³)`
  0-1 BFS           `O(V + E)`
  Kruskal           `O(E log E)`
  Prim + Heap       `O(E log V)`
  DSU               近似 `O(1)` 均摊
  Tarjan SCC        `O(V + E)`
  桥 / 割点         `O(V + E)`
  LCA 倍增预处理    `O(V log V)`
  LCA 查询          `O(log V)`

# 学习原则

每道图论题优先完成：

``` text
现实问题
↓
节点与边
↓
有向 / 无向
↓
权值性质
↓
图的特殊结构
↓
问题目标
↓
数据规模
↓
算法选择
↓
正确性与复杂度分析
```

最终目标：

> 面对陌生问题，能够先建立正确的图模型，再根据图结构、边权性质、问题目标和复杂度约束自行选择算法，而不是依赖题目关键词套模板。
